# Licensing Plan

## Code

This mod's code is licensed under **GPL-3.0-or-later**.

## Derived Media (Important)

We plan to derive seasonal textures from existing VoxeLibre `mcl_*` textures.

VoxeLibre legal summary states:

- Media defaults are **CC BY-SA 3.0**, unless noted otherwise.
- Some specific assets are under **CC BY-SA 4.0** or **CC BY 4.0**.

Implication for this mod:

- Each derived asset must keep a license compatible with its source asset.
- We must track provenance and attribution per derived file.
- If source assets have mixed licenses, derived outputs may need mixed licensing too.

## Repository Policy

Before adding generated/edited textures, record them in `assets/ATTRIBUTION.md` with:

- source file path,
- source author/project,
- source license,
- transformation notes,
- resulting license.
