# seasons

Smooth biome-driven seasons for VoxeLibre/Luanti.

## Status

Skeleton only. No gameplay changes are active yet.

## Goals

- 100-day year with smooth progression.
- Biome-driven seasonality (no coordinate latitude).
- Continuous season signals for visuals and systems:
  - `thermal`
  - `moisture`
  - `dthermal_dt`

See [docs/VISION.md](docs/VISION.md) for the design.
